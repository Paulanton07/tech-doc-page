# Electron Documentation Site

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-success)](https://paulanton07.github.io/tech-doc-page/)

A comprehensive, multi-page documentation site for learning Electron framework development. Built as a modern, responsive static site optimized for GitHub Pages hosting.

## 🌐 Live Site

Visit the live documentation at: **[https://paulanton07.github.io/tech-doc-page/](https://paulanton07.github.io/tech-doc-page/)**

## 📖 About

This documentation covers essential topics for building cross-platform desktop applications with Electron:

- **Introduction to Electron** - Framework overview and key concepts
- **Setup and Installation** - Getting started with your development environment
- **Main vs Renderer Process** - Understanding Electron's dual-process architecture
- **Building Your First App** - Step-by-step guide to creating your first application
- **Packaging and Distribution** - How to package and distribute your apps
- **Best Practices and Security** - Essential security guidelines and best practices

## 💻 Local Development

To view the documentation locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/Paulanton07/tech-doc-page.git
   cd tech-doc-page
   ```

2. Open `index.html` in your web browser, or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js http-server
   npx http-server
   ```

3. Navigate to `http://localhost:8000` in your browser

## 🌟 GitHub Pages Deployment

This site is configured for GitHub Pages deployment from the main branch:

1. Go to repository Settings → Pages
2. Under "Source", select "Deploy from a branch"
3. Select branch: `main`
4. Select folder: `/ (root)`
5. Click Save

The site will be automatically deployed to `https://paulanton07.github.io/tech-doc-page/`
