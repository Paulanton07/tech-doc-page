Step 1: Merge the Pull Request First (Important!)
Before enabling GitHub Pages, you should merge the PR so the new multi-page structure is on your main branch:

Go to: https://github.com/Paulanton07/tech-doc-page/pull/1
Click the green "Merge pull request" button
Click "Confirm merge"
Step 2: Enable GitHub Pages
After merging, follow these steps:

Go to your repository: https://github.com/Paulanton07/tech-doc-page

Click "Settings" (top menu bar)

Click "Pages" (in the left sidebar under "Code and automation")

Configure the source:

Under "Source", select: "Deploy from a branch"
Under "Branch", select:
Branch: main
Folder: / (root)
Click "Save"
Wait a minute or two for GitHub to build your site

Refresh the page - you'll see a message like:

"Your site is live at https://paulanton07.github.io/tech-doc-page/"
